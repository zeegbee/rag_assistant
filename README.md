# RAG-ассистент (OpenAI API)

Консольный ассистент, который отвечает на вопросы по базе знаний с помощью
Retrieval-Augmented Generation: находит релевантные фрагменты документов
в векторной базе и передаёт их в языковую модель как контекст.

## Возможности

- Векторный поиск по документам: ChromaDB + embeddings `text-embedding-3-small`
- Генерация ответов через `gpt-4o-mini` строго по найденному контексту
- Кеширование ответов в SQLite: повторные вопросы не тратят запросы к API
- Оценка качества системы через [RAGAS](https://docs.ragas.io/)
  (метрики Faithfulness и Context Precision)

## Структура проекта

```
├── app.py              # консольное приложение
├── rag_pipeline.py     # RAG pipeline: кеш → поиск → промпт → генерация
├── vector_store.py     # векторное хранилище (ChromaDB + OpenAI embeddings)
├── cache.py            # кеш ответов в SQLite
├── evaluate_ragas.py   # оценка качества через RAGAS
├── data/docs.txt       # база знаний (статьи по ML/NLP/RAG)
├── requirements.txt
└── .env.example        # шаблон файла с ключом API
```

## Установка

Нужен Python 3.11+ (проверено на 3.13) и ключ OpenAI API.

```bash
git clone <url-репозитория>
cd assistant_api

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

Создайте файл `.env` по шаблону и укажите в нём свой ключ:

```bash
cp .env.example .env
```

```
OPENAI_API_KEY=your-key-here
```

## Запуск

```bash
python app.py
```

При первом запуске документы из `data/docs.txt` разбиваются на фрагменты
и загружаются в векторную базу `chroma_db/`. Следующие запуски используют
уже готовую базу.

Команды в приложении:

| Команда              | Действие                         |
|----------------------|----------------------------------|
| `stats`              | статистика базы и кеша           |
| `clear`              | очистить кеш ответов             |
| `exit`, `quit`, `q`  | выход                            |

## Оценка качества (RAGAS)

```bash
python evaluate_ragas.py
```

Скрипт прогоняет 12 тестовых вопросов с эталонными ответами через RAG-систему
и считает метрики:

- **Faithfulness** — насколько ответ опирается на найденный контекст
  (нет ли выдуманных фактов);
- **Context Precision** — насколько найденные фрагменты полезны для ответа.

Вопросы разделены на типы: определения, факты, перефразировки, сравнения,
составные вопросы (ответ из нескольких фрагментов) и вопросы вне базы знаний.
Результаты выводятся общими средними значениями, по типам вопросов
и по каждому вопросу отдельно.

Для вопросов вне базы Context Precision равен 0 — это ожидаемо: подходящих
документов нет. Важно, чтобы при этом Faithfulness оставался высоким,
то есть модель признавала отсутствие информации, а не выдумывала ответ.

> Оценка использует OpenAI API (модель-судья RAGAS), поэтому каждый запуск
> тратит запросы к API. Кеш при оценке не используется.

## Примечание о версиях

RAGAS 0.3.x несовместим с `langchain` 1.x и `langchain-community` 0.4+,
поэтому их версии в `requirements.txt` ограничены сверху.
